# ADR template

Copy this file to `adr-<nnn>-<slug>.md`, fill it in, and add the row to the index in
`README.md`. An ADR is immutable once accepted: a changed decision gets a new record that
supersedes the old one, and the old one says so.

**Status:** Accepted | Proposed | Deprecated | Superseded

**Context:**
[What is the issue that we're seeing that is motivating this decision?]

**Decision:**
[What is the change that we're proposing and/or doing?]

**Consequences:**
[What becomes easier or more difficult to do because of this change?]
