# Three delivered stories' scenarios are not committed to product/spec on main — SharedScenariosTest fails on their titles; how does this build pass?

## Question
After decision 01 (d5ce1e9) this story's own title passes. The build gate's `./gradlew test` now fails only on
`src/test/java/dev/domaincentric/sample/ecommerce/specification/SharedScenariosTest.java:113`
(`everyBrowserTestIsAScenarioOfThisShopsSpecification`) with the titles of three *other* stories:
"Each listener counts its own attempts", "Registration says the account was created", "Remove takes the line out".

Their browser tests are on this branch (commits c965406, acf8940, a672016 on main). Their stories are `status: delivered`
in `product/epics`, so the test no longer takes their titles from the stories. Their scenarios
(`each-listener-counts-its-own-attempts`, `registration-says-the-account-was-created`, `remove-takes-the-line-out`) are in
the main checkout's `product/spec/**/scenarios.md`, but `git log -S remove-takes-the-line-out main -- product/spec` finds
no commit: the delivering gate's spec merge for these three stories looks uncommitted on main, and this worktree's
`product/spec` (from a672016) does not hold them. The story's own two tests, the architecture suite and the formatter
are green; the build may not write `product/spec` or change a test.

## Options
- a: Commit the three scenarios' spec merge on main, then integrate main into this story's branch (or let the runner
  rebase it) and run the build stage again; nothing changes in this story's code.
- b: Let `SharedScenariosTest` also accept the titles of delivered stories whose scenario is not in `product/spec` yet
  (changes a test, by hand on main); it would then no longer catch a delivery that never reached the spec.
- c: Accept the build as it is: the one red test is outside this story's footprint, and the delivering gate's merge
  brings the scenarios in.

## Recommendation
a — the spec on main is missing what three deliveries already promised; committing it fixes the cause for every story
in flight, and keeps the test's guard intact.
